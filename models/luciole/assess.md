# Assess - Luciole 1.1 Instruct (23B, 8B, 1B)

_Openness, licence, provenance, EU AI Act position, safety, evaluation and the AOI score._

<!-- item: intended-use -->
## Intended & out-of-scope use

Use the Instruct models for general instruction following in French and English, after testing them on your own task. The card says the model should be tested before it enters an industrial pipeline. It recommends further training for specific uses and a RAG pipeline for knowledge (`ev-card-instruct`).

Code generation and maths need extra training, according to the card. The base model is a next-word predictor and must be fine-tuned before end use (`ev-card-base`). No document sets out forbidden uses, and no acceptable-use policy ships.

<!-- item: limitations -->
## Known limitations, bias & failure modes

All items come from the publisher's cards and dataset cards (`ev-card-instruct`, `ev-posttrain-data`, `ev-pretrain-data`).

- The model hallucinates and can memorise little at its size.
- Post-training used almost entirely English data, although the base saw about 30% French.
- Post-training sequences were 16,384 tokens, against a 131k base window.
- Tool calling is marked work in progress.
- Web and public-domain sources carry toxic and historically biased text, and filtering is described as ongoing.
- Much of the post-training data was generated by Qwen3 and other third-party open-weights models, which the dataset card says can introduce linguistic and cultural bias.

<!-- item: license -->
## Licence terms & permitted use

The Instruct weights are Apache-2.0, ungated, with commercial use allowed. The card says the model is released "under the Apache License 2.0" with copyright held by LINAGORA SAS. The NOTICE file in the code repository names LINAGORA SAS as owner of the models (`ev-card-instruct`, `ev-notice`).

The Instruct repos contain no LICENSE file. The Base repos contain a LICENSE.md that holds the Apache-2.0 text with the copyright line left blank (`ev-licence-file`). Apache-2.0 section 4 expects a copy of the licence to travel with redistributed copies, so add the text yourself.

The training code is GPL-3.0 (`ev-code-licence`). Copying or distributing the code requires GPL-3.0 for the derivative. The weights are separately licensed and the NOTICE file does not extend the GPL to them.

The post-training data was generated by Qwen3, Ministral-3 and, through NVIDIA source sets, GPT-OSS-120B and Qwen3-235B. Their Hugging Face tags show Apache-2.0 and no output restriction was found. The licence files of Ministral-3 were not opened (`ev-upstream`).

The dataset licences differ from the weights. Both datasets are CC-BY-SA-4.0 and say each source keeps its own licence.

<!-- item: provenance -->
## Supply-chain & provenance

The canonical source is huggingface.co/OpenLLM-France, which Hugging Face lists as not verified, with 20 members. The 23B Instruct repo holds ten safetensors shards, no pickle file and no custom code. Hugging Face flagged no file, and it lists LFS hashes. The publisher gives no separate checksum file and no signature. That is about 4 of 8 checklist boxes (`ev-hf-platform`).

The Instruct models descend from Luciole-23B-Base, which the cards link as the base model. The base card gives an initialiser range, a Nemotron3-22B architecture recipe from NVIDIA's NeMo framework and no parent checkpoint. It does not say the model was trained from scratch. The data points to random initialisation, but the cards do not state it (`ev-card-base`).

Independence from other models is limited. The pretraining mix includes Qwen3-8B reformulations of FineWeb 2 and Wikipedia, and model-generated NVIDIA and OpenThoughts sets (`ev-pretrain-data`). The post-training data is largely Qwen3 output, and the chat template is modelled on Qwen3's (`ev-posttrain-data`, `ev-card-instruct`).

The 8B uses a hybrid Mamba-transformer and its repos ship Python modelling code. Review that code before running it (`ev-siblings`).

<!-- item: eu-ai-act -->
## EU AI Act posture

Luciole is a general-purpose AI model. The base card gives about 4.9 trillion tokens and 576,587 H100 GPU hours, which is about 6.8e23 FLOPs by the 6 x parameters x tokens estimate. That is below the 1e25 systemic-risk threshold, so Article 55 does not apply (`ev-card-base`).

Apache-2.0 would normally support the Article 53 open-source exemption, and weights, architecture and usage information are public. The exemption never covers a copyright policy or a public training-content summary.

The dataset cards list each source with its licence, describe robots.txt filtering and PII removal, and offer an opt-out form. This covers most of a training-content summary, in a format other than the AI Office template. No separate copyright policy, Annex XI document or technical report exists (`ev-pretrain-data`, `ev-report-absent`). Code of Practice signatory status is not stated. A fine-tuner who places a derivative on the EU market may become a provider for it. This is guidance, not legal advice.

Every figure is the publisher's. The Instruct card shows a bar chart against four 22B to 24B instruct models (`ev-bench`).

| ifeval / ifeval-fr | about 0.83 / 0.74 | first of five on both |

The base card gives French, English, multilingual, translation and RULER figures against Gaperon-24B, EuroLLM-22B and Mistral-Small-24B-Base. No independent re-run was found.

## Contradictions and surprises

- The Thinking card documents `enable_thinking=False`, so its thinking can be switched off.
- The cards and the consortium site say the data is open-licensed, yet the pretraining dataset card lists Claire sources under CC BY-NC-SA 4.0 and one source with no stated licence under a single CC-BY-SA-4.0 label. The cards do not say whether Claire entered the training mix.
- The site says datasets are republished for auditability. Three English web subsets are on a separate server, and the Base card says checkpoints use revision tags, but Hugging Face lists only the main branch.
- The base card does not say "from scratch", and both data mixes contain output of other models.
- The training code is GPL-3.0 and the weights are Apache-2.0.
- The Modelfile comment in the GGUF repo names "Luciole-1B-Instruct-1.2", which matches no published repo.
