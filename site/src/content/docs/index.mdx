New to this? **[Start here: what you are actually deciding](/start-here/)** answers the three
questions that matter, in plain language, without benchmarks: can it be restricted, what happens to
your data, and will you be locked in.

## What this is

A **library, not a report.** For each open-source model (and the providers that serve it),
we document everything an organisation needs to make an informed decision - organised into
four domains that follow the adopter's journey.

<CardGrid>
  <Card title="Assess" icon="magnifier">Should we adopt it? Openness, license, provenance, EU AI Act posture, safety, benchmarks, and the AOI trust score.</Card>
  <Card title="Implement" icon="rocket">How do we deploy it? Install paths, hardware, serving stacks, quantization, fine-tuning, and safe-deployment controls.</Card>
  <Card title="Use" icon="open-book">What can it do? Capabilities, context window, prompt/chat template, languages, tool-use, structured output.</Card>
  <Card title="Support" icon="setting">How do we keep it running? Troubleshooting, versioning, security disclosure, community channels.</Card>
</CardGrid>

## Every claim is labelled

Each section carries a source badge - <span class="oh-badge oh-badge--aggregated">aggregated</span>
(cited from an existing source), <span class="oh-badge oh-badge--onehill_generated">OneHill-tested</span>
(we ran or verified it ourselves), or <span class="oh-badge oh-badge--gap">gap</span>
(cannot be gathered nor provided - stated explicitly, with the reason). Every domain shows a
**completeness** meter, so you can see at a glance how much of the expected documentation set is
filled in and what remains a stated gap.

Built on accepted standards - Diátaxis, ISO/IEC/IEEE 26514, the Good Docs Project, Model
Cards, the Model Openness Framework, and the EU AI Act. Independent, sourced, and dated.
