New to this? [Start here](/start-here/) explains the ownership level and the four factors behind it: use and modify, transparency, reliability and data control.

## What this is

For each open-weight model, and the providers that serve it, the library documents what an organisation needs to decide, in four domains that follow the adopter's journey.

<CardGrid>
  <Card title="Assess" icon="magnifier">Openness, licence, provenance, EU AI Act position, safety, evaluation and the AOI score.</Card>
  <Card title="Implement" icon="rocket">Installation, hardware, serving, safe-deployment controls, quantisation, fine-tuning and integration.</Card>
  <Card title="Use" icon="open-book">Capabilities, context window, chat template, languages, tool use and structured output.</Card>
  <Card title="Support" icon="setting">Troubleshooting, versions, security disclosure, channels and deprecation.</Card>
</CardGrid>

## Every claim is labelled

Each section carries a source badge: <span class="oh-badge oh-badge--aggregated">aggregated</span> (cited from an existing source), <span class="oh-badge oh-badge--onehill_generated">OneHill-tested</span> (produced or verified by OneHill with a recorded method, not yet used) or <span class="oh-badge oh-badge--gap">gap</span> (could not be gathered, with the reason). Every domain shows a completeness meter.

The structure follows Diátaxis, ISO/IEC/IEEE 26514, the Good Docs Project, Model Cards, the Model Openness Framework and the EU AI Act.
